# End-to-end evaluation, 2026-10-18

Two scenarios where an idea looks new but is already covered. Live services, no API keys. Raw outputs are in the project's `work/eval/`.

## Eval 5: UPFD graph vs no-graph

**Known prior work:**
- Karn & Jensen 2025 (arXiv 2512.06638): GNNs vs an MLP on the same features, edge rewiring, feature shuffling.
- The UPFD paper's own edge-removal ablation (arXiv 2104.12259).

| Run | Queries | New features | Karn & Jensen rank | Signal |
| --- | --- | --- | --- | --- |
| Old tool, first audit | original 7 | none | not retrieved | `no_close_match` |
| New tool, features off | new 4 | `--expand 0`, no design or seed | 1 | `no_close_match` (overlap 0.33 < 0.6) |
| New tool | new 4 | design (4), seed UPFD, expand 3 | 1, flagged "possibly the same experiment" (3 of 4 design elements) | `close_prior_work_found` |
| New tool, original wording | original 7 | design, seed, expand | not retrieved | `close_prior_work_found` (from other papers) |

`fulltext --id 2104.12259` surfaced, without any manual reading:
- the news-only MLP baselines;
- the "-EXO" edge-removal ablation;
- "averaged over five different runnings";
- the 20/10/70 split.

These are the facts that made the original proposal a duplicate.

**What helped:**
- **Design elements.** They change the verdict when the right paper is retrieved but worded differently.
- **Full-text extraction.** It finds controls hidden in the original paper's ablation section.

**What did not help in this case:**
- **Citation expansion.** OpenAlex records no references for the Karn & Jensen preprint (checked: 0 `referenced_works`), so no citation route can reach it.
- **Wording still decides retrieval.** With the original query wording, the paper was not retrieved at all.
- **Design-match precision is low.** 20 papers matched 2+ elements, including generic GNN papers such as GNN-FiLM and the Long Range Graph Benchmark.

A bug was found and fixed during this run. OpenAlex's citing-works text filter needs every word to match, so sentence-length probes returned nothing. Seeds now use 2–3-word probes.

## Eval 6: leakage-free ogbn-arxiv for LLM memorisation (held out)

**Known prior work:** Huang et al. 2023 (arXiv 2309.16595), which built arxiv-2023 for exactly this test. This paper was not used to write the queries.

**Result:** a miss.
- OpenAlex (HTTP 429) and Semantic Scholar were both rate-limited for the whole run, so the seed's citing works could not be searched.
- The target paper was not retrieved.
- The tool reported `no_close_match_in_this_search`, ceiling `low`, and named both failed sources.

Its interpretation first said "coverage was reasonable". That wording was fixed so a failed scholarly index is reported as degraded coverage, with a regression test.

## Conclusions

- The toolkit now refuses the kind of recommendation that started this investigation: a `go` or a high novelty score built on abstracts, with no leakage, baseline or protocol check. It also flags differently worded same-design papers when they are retrieved.
- Retrieval itself is still lexical and depends on rate-limited indexes. Two of the three runs with the new features enabled missed the known prior work. A web search for the design in plain words remains a required step (`references/adversarial-verification.md`, step A).
- These results come from two scenarios with known answers. They are not a measured detection rate.
